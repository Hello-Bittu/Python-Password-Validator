# 🔒 Python Password Strength Validator

A terminal-based application that analyzes passwords and rates their security strength based on industry-standard criteria. Built entirely with core Python fundamentals.

## 🚀 Features
* **Real-time Validation:** Continuously prompts the user to test multiple passwords without restarting the program.
* **Algorithmic Scoring:** Checks for minimum length (8+ characters), uppercase letters, lowercase letters, numbers, and special symbols.
* **Match-Case Logic:** Utilizes Python's structural pattern matching to evaluate scores and output exact security ratings (WEAK, MODERATE, STRONG).

## 🧠 Core Concepts Utilized
This project was built to practice and demonstrate proficiency in Python fundamentals:
* `while` and `for` loops
* String iteration and string methods (`.isupper()`, `.isalpha()`, `.isalnum()`)
* Boolean flags and arithmetic operators
* `if/elif/else` and `match-case` conditional statements
